# Homepage hero change

Only homepage hero layout styles were adjusted: the existing doctor photo is smaller on desktop, the image wrapper has no card border/background/shadow, and a restrained soft edge fade is applied. The existing photo asset and headline/CTA content are retained. Mobile uses a narrower image size.

No new image was generated or substituted. Open `index.html` in VS Code/Live Server to preview. This CSS change has not been visually verified in a live browser.
