# Homepage hero portrait refinement

Changed only the homepage stylesheet with a targeted visual override intended to remove the portrait's card-like background, border, rounded frame, and shadow, and blend the image into the hero background using a subtle bottom fade. The existing headline and CTA content are preserved.

Please preview in VS Code at desktop and mobile widths. The selectors are scoped to common hero portrait wrappers; if the exact current markup uses a different wrapper class, inspect the hero image element and adjust the selectors to match it. No live deployment was performed.
